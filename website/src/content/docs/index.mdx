<div class="cda-section-head">
<h2>What it does</h2>
<p>The package reads Archi's native XML and exposes its semantics without reinterpreting them for another standard.</p>
</div>

<div class="cda-capabilities">

<div class="cda-capability">
<h3><span class="cda-kicker">Parse</span>Read native Archi models</h3>
<p>Work programmatically with an Archi model without touching Archi's XML structure — folders, elements, relationships, views and diagrams.</p>
</div>

<div class="cda-capability">
<h3><span class="cda-kicker">Validate</span>Check structural integrity</h3>
<p>Detect missing or duplicate ids and dangling cross-references across all seven id-bearing collections with one call.</p>
</div>

<div class="cda-capability">
<h3><span class="cda-kicker">Build</span>Consume the typed model</h3>
<p>Use the resulting <code>ArchiModel</code> as a foundation for impact analysis, governance, GitOps, IDEs and other developer tooling.</p>
</div>

</div>

<div class="cda-section-head">
<h2>In two lines</h2>
<p>v{rootPkg.version} · ESM · Node {rootPkg.engines.node.replaceAll(' || ', ', ')} and modern browser bundlers</p>
</div>

<div class="cda-example">
<div class="cda-example-caption">TypeScript — parse and validate</div>

```ts
import { parseArchiModel, validateArchiModel } from '@cda/archi-semantic-core';

const model = parseArchiModel(xml);

console.log(model.elements[0].type); // "BusinessActor", not "archimate:BusinessActor"

const { valid, errors } = validateArchiModel(model);
```

</div>

</div>
